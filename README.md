# Clinical Studies Management

**Odoo module that automates the planning of mental-health clinical studies: study templates, scoring-based assignment of professionals and participants, and automatic session scheduling.**

Running a clinical study means matching the right therapists to each study and each participant, and then fitting dozens of sessions into everyone's calendar. This module turns that manual coordination into a configurable, auditable process inside Odoo.

## Features

**Study templates.** Minimum participants and therapists, sessions per week, session types with their own count and duration, required specialities (e.g. depression, anxiety, addictions) and expected years of experience. The total duration is computed automatically.

**Professional-to-study assignment.** Each professional gets an affinity score from 0 to 100:

| Factor | Weight |
| --- | --- |
| Experience (years vs. required) | 40% |
| Speciality match | 40% |
| Current workload (active participants) | 20% |

The top N professionals above 60 points are assigned automatically, and each assignment can be confirmed or declined by hand.

**Participant-to-professional assignment.** Compatibility score from 0 to 100 based on shared available days (40%), preferred time slots (30%) and the professional's current load (30%). The participant is assigned to the most compatible professional above 50 points.

**Automatic scheduling.** Sessions are distributed respecting sessions per week, required session types, common available days, compatible time slots and session durations, and are added to the Odoo calendar with a status workflow (scheduled → confirmed → completed / cancelled).

**Reports and access control.** A PDF workload report per professional (QWeb) and two roles, principal and associate professional, enforced with access rights and record rules.

## Structure

```
models/     study templates, sessions, session types, specialities, professionals, participants, assignments
wizards/    template assignment and professional report
reports/    QWeb report and parser
security/   groups, access rights, record rules
data/       specialities, available days, session types, demo data
tools/      synthetic demo-data generator
docs/       GitHub Pages site with the functional spec
```

## Installation

1. Copy the folder into your Odoo `addons` path.
2. Update the apps list and install **Clinical Studies Management** (depends on `base`, `mail`, `calendar` and `hr`).
3. Demo users: `manager_demo` / `manager_demo` and `prof_demo` / `prof_demo`.

All demo data (names, phone numbers) is synthetic and generated by `tools/generate_demo_data.py`.
